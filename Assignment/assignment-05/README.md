# 🍔 Asad's Bistro
A 4-page responsive food/restaurant website built using pure **HTML5** — created as a practical assignment to demonstrate multi-page website structure, navigation, and semantic HTML.

> ### 🚀 View the Website
> For a **better user-friendly experience**, please visit the live website instead of browsing the raw code folders!
>
> 👉 **[Launch 🍔 Asad's Bistro l 💻](https://your-username.github.io/Food-Website/index.html)**

## 🌐 Live Pages
| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero banner with welcome message, featured food items, and special offer section |
| Menu | `menu.html` | Categorized menu grid — Burgers, Pizza, Drinks, Desserts |
| About | `about.html` | Restaurant story, mission, vision, and why-choose-us points |
| Contact | `contact.html` | Restaurant address, phone number, email, and timings |

## ✨ Features
- Consistent navigation bar and footer linking all 4 pages
- Hero section with blurred background image and overlay text
- Scrolling marquee banner for offers and announcements
- Featured items showcase with image, name, and description
- Menu items organized by category with price and description
- Special deal / promo section with call-to-action button
- Warm food-themed color palette (`chocolate` & `orange` accents)

## 🛠️ Built With
- HTML5
- Inline `<style>` attributes (no external CSS framework)
- Table-based and Flexbox layouts

## 🚀 How to Run
1. Clone or download this repository
2. Open `index.html` in any web browser
3. Navigate between pages using the top nav bar

```bash
git clone https://github.com/your-username/Food-Website.git
cd Food-Website
```

No build tools or dependencies required — just open and view.

## 🖼 Note on Images
Add your own food images into the `images/` folder (e.g. `burger.jpg`, `pizza.jpg`, `cake.jpg`, etc.) and your logo into `Images/logo/main1.png` for the pictures to display correctly.
