# 📸 Asad's Photography Studio

A 4-page responsive photography portfolio website built using pure **HTML5** and **CSS3** — created as a practical assignment to demonstrate multi-page website structure, navigation, and semantic HTML.
> ### 🚀 View the Website
> For **better user-friendly experience** , please visit the live website application instead of browsing the raw code folders!
> 
> 👉 **[Launch 📸 Asad's Photography Studio l 💻](https://asad694.github.io/Saylani-Modern_Web_App/Assignment/assignment-03/index.html)**

## 🌐 Live Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero banner, studio intro, and featured work showcase |
| Gallery | `gallery.html` | Categorized photo grid — Weddings, Portraits, Nature |
| About | `about.html` | Photographer bio, skills, and equipment list |
| Contact | `contact.html` | Contact info and a message form |

## ✨ Features

- Fully responsive layout using Flexbox and CSS Grid
- Consistent navigation bar linking all 4 pages
- Hero sections with background images and overlays
- Image galleries organized by category
- Skills and equipment lists (ordered & unordered)
- Contact page with form and studio details
- Dark theme with gold accent color (`#d4af37`)

## 🛠️ Built With

- HTML5
- CSS3 (inline `<style>` blocks — no external frameworks)
- Images sourced from [Unsplash](https://unsplash.com)

## 🚀 How to Run

1. Clone or download this repository
2. Open `index.html` in any web browser
3. Navigate between pages using the top nav bar

```bash
git clone https://github.com/your-username/photography-website.git
cd photography-website
```

No build tools or dependencies required — just open and view.
